# 数据说明

## 概要

名称：Wind Turbine RUL Datasets / 风机剩余寿命预测模拟数据集。数据版本：v1.0.0。
三类数据，每种格式分别共4,440行。载荷、HI的两种格式数值一致；寿命CSV与Parquet是不同的模拟版本，必须分别使用。

## 来源

文件直接复制自本地软件项目 `resources/example_data/` 中的三组既有模拟样例。它们是合成/模拟数据，不是现场采集或实际维修故障记录。
本次整理保留原文件字节，校验值见根目录manifest.json。生成公式、固定种子、物理单位标定及可复现的原始生成器未随数据包提供，因此不宣称可精确重生成或符合某一风机型号。

## 分析单位

- 载荷和HI：以turbine_id区分6台模拟机组，两个表各自独立。相同ID不构成经验证的跨数据集关联。
- 寿命Parquet：120条部件记录，四类各30条；CSV：120条均为齿轮箱轴承。两版均44失效、76右删失，但逐行数值不同，不能拼接。ID为样例标识，不能据此认定有120台现场风机。
- timestamp/date为模拟时间轴，不表明发生过真实设备事件。

## 推荐用途

寿命分析软件输入测试、教学演示、可视化、异常输入和右删失处理验证。
可作为算法代码检查用的输入，但并未提供足以验证真实预测误差的独立真值。

## 局限

- 不提供已校准材料曲线、结构换算系数、全寿命载荷或已服役历史；不能仅靠短时载荷确定真实疲劳剩余年限。
- HI下降趋势和寿命样本是模拟设置，不代表任何型号的真实退化过程。
- 右删失标志必须参与需要删失处理的生存分析；未失效记录不能直接视为故障。
- 运行时长、HI阈值与使用环境的映射没有现场校准；不能用于直接制定维护期限或安全运行决策。
- 合成数据不等于已经匿名化的真实数据；本仓库并无真实风场数据的主张。
