# 数据集说明文档 (Data Card)

## 1. 概要信息

- **数据集名称**：Wind Turbine RUL Datasets / 风电机组运行寿命与状态分析真实数据集
- **当前版本**：v1.0.1
- **涵盖领域**：风电工程、风电机组预测性维护（PdM）、剩余使用寿命（RUL）预测、结构健康监测（SHM）与设备可靠性工程。
- **存储格式**：Parquet（列式存储，推荐）与 CSV（通用格式）。

## 2. 工程背景与数据来源

本数据集面向风力发电机组在真实服役工况下的关键部件健康管理与寿命预测需求，收录并整理了三类代表性运行监测与状态寿命数据：
1. **风电机组叶片高频载荷与转速监测数据**：反映机组在实际风况与运行控制下的气动与结构受载波动。
2. **机组关键轴承长周期健康状态与温度残差数据**：记录机组轴承随服役历时推进的健康指数（HI）衰减历程。
3. **风电关键部件服役寿命与故障事件记录**：记录机组主轴承、齿轮箱轴承、发电机轴承和变桨电机等部件在实际运行中的累计工作时长、故障失效及右删失状态。

## 3. 数据集结构与分析单元

- **叶片载荷时序 (`rul_blade_load_fatigue`)**：
  - 机组规模：6 台风电机组（WT01–WT06）。
  - 采样特征：10 Hz 高频采样（采样间隔 0.1 s），每台机组连续记录 600 点时序。
  - 关键测点：三个叶片的摆振方向实测载荷（`blade_edge_1/2/3`）与发电机转速（`generator_rpm`）。
- **轴承健康退化时序 (`rul_bearing_degradation`)**：
  - 机组规模：6 台风电机组（WT01–WT06）。
  - 跟踪周期：120 天连续运行跟踪（`operating_days`: 0–119）。
  - 监测指标：包含轴承温度测点残差（`bearing_temp_residual_degC`）与多维融合健康指数（`health_index_hi`，取值范围 $0 < HI \le 1.0$）。
- **部件故障与寿命记录 (`rul_component_failures`)**：
  - 部件类型：包含主轴承（Main_Bearing）、齿轮箱轴承（Gearbox_Bearing）、发电机轴承（Generator_Bearing）与变桨电机（Pitch_Motor）。
  - 事件统计：共 120 条服役记录，其中包含 44 条实际发生的故障停机记录（`failed_event = 1`）以及 76 条在统计截止期仍安全运转的右删失记录（`failed_event = 0`）。
  - 工况特征：记录了各部件服役期间的平均运行负载系数（`avg_load_factor`）与环境温度（`avg_ambient_temp`）。

## 4. 推荐应用场景

- **雨流计数与载荷谱编制**：提取载荷幅值-均值二维谱，结合材料 S-N 疲劳曲线与 Palmgren-Miner 准则评估疲劳累积损伤。
- **设备退化建模与 RUL 预测**：利用长周期健康指数拟合退化轨迹（指数模型、多项式模型、高斯过程等），实现失效阈值预警与剩余天数预测。
- **设备可靠性与生存分析**：基于右删失数据的两参数 Weibull 极大似然估计（MLE）、Kaplan-Meier 生存率估计以及浴盆曲线故障率建模。
- **状态监测系统（CMS/SCADA）验证**：为风电智能分析算法、工业监测桌面软件及云端运维平台提供标准输入验证。

## 5. 数据质量与完整性

所有数据记录完整，无缺失值（NaN / Null），数值全部处于物理可信的合理区间。根目录提供了 `manifest.json` 与校验脚本 `scripts/validate.py`，支持随时对数据文件的 SHA-256 哈希及维度进行离线校验。
