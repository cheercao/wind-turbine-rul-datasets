|---|---|---|
| **加密完整性** | 六项数据文件的 SHA-256 哈希值与 `manifest.json` 元数据严格对齐 | 完全通过 (100%) |
| **存储双格式一致性**| 列式 Parquet 与通用 CSV 的列序、数据类型与行数严格对应 | 完全通过 (100%) |
| **数值无损映射** | 浮点特征值在跨格式转换中的相对偏差严格满足 $\le 10^{-12}$ | 完全通过 (100%) |

| **退化指标单调区间**| Task 2 健康指数全部处于物理定义域 $(0, 1.0]$，具备长程退化趋势 | 完全通过 (100%) |
