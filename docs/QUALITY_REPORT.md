# 数据质量与校验报告 (Quality Report)

本报告针对仓库核心数据文件执行了全面的质量与格式一致性检验。可通过运行 `python scripts/validate.py` 自动化复核以下各项指标：

| 校验大项 | 详细检查内容 | 检验状态 |
|---|---|---|
| **文件完整性** | 六个核心数据文件的 SHA-256 哈希值与 manifest.json 完全一致 | 通过 |
| **结构一致性** | CSV 与 Parquet 双格式的列名定义、列序及记录行数完全一致 | 通过 |
| **数值无损比对** | 载荷、HI 两种格式的浮点数值与日期字段完全一致（浮点容差 1e-12） | 通过 |
| **数据清洗完整度** | 全部字段均无缺失值（无 NaN / Null），数值全部为有限有效值 | 通过 |
| **叶片载荷时序** | 6 台机组，每台各 600 行，采样时间间隔严格为 0.1 秒（10 Hz） | 通过 |
| **轴承退化时序** | 6 台机组，每台各 120 天跟踪，健康指数满足 $0 < HI \le 1.0$ | 通过 |
| **部件寿命记录** | 44 次真实失效记录，76 次有效右删失记录；运行小时数均大于 0 | 通过 |
| **物理范围合理性** | 转速、温度残差、环境温度与负载系数均在工程正常范围之内 | 通过 |

通过上述检查，证明数据结构完备、格式标准、数值稳定无缺漏，可直接导入风电寿命分析、可靠性建模及状态监测算法体系进行验证与应用。
