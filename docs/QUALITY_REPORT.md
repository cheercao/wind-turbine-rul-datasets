# 数据质量检查

以下结果针对仓库v1.0.0的六个原始文件，可用 `python scripts/validate.py` 重复检查。

| 检查项 | 结果 |
|---|---|
| 六个原始文件SHA-256与首次上传清单一致 | 通过 |
| CSV / Parquet字段顺序、记录行数一致 | 通过 |
| 载荷、HI两种格式的数值、字符串及日期一致 | 通过；数值比较容差1e-12 |
| 寿命CSV与Parquet逐行一致 | 不一致，为原始文件中已有的两个版本；分别校验，不修改原值 |
| 全字段无缺失，数值为有限值 | 通过 |
| 疲劳：6组，每组600行，采样间隔0.1秒 | 通过 |
| 退化：6组，每组120行，运行天数0–119 | 通过 |
| 退化：0 < HI ≤ 1 | 通过 |
| 寿命Parquet：4类部件，每类30行；CSV：齿轮箱轴承120行 | 通过 |
| 寿命：44失效、76右删失，标志均为0或1 | 通过 |
| 寿命：观察运行小时数均为正值 | 通过 |

这些检查证明文件完整性及约定的格式一致性，不证明模拟过程符合真实风机物理，也不证明任何寿命预测算法的准确率。
